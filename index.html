How I work

I'm a Senior Data Analyst at Badho, a B2B FMCG marketplace connecting brands, distributors and retailers. Since May 2026 I've built its internal analytics platform end to end (the query, the API route and the chart) with Claude Code as my pair programmer.

Most of it sits where money moves: P&L statements, courier COD remittances, refunds, funding pools and payouts. There, a report that's almost right is worse than no report.

Before analytics I led a 50+ member operations team, so I build for the person who has to act on the number. Every figure on this page says where it came from; business figures stay inside the company.

01

Dashboards finance can sign off on

02

Built from scratch, SQL to screen

No BI tool between me and the data. I write the query, the API route and the chart, so when a number looks wrong I can follow it all the way down.

03

Show the query

262 of 298 API routes return the SQL that produced them, with its parameters and a copy button beside the chart.

04

Preview before you write

Anything that changes money runs as a preview first. Transfers post both sides in one transaction; re-running a sheet changes nothing.

05

Leave a trail

Approvals, transfers and remittance writes are audit-logged: who, what and which build. “Who changed this?” always has an answer.
